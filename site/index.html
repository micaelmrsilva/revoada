Isso fere os termos dos provedores?

O app usa o login de cada CLI oficial, sem copiar token nem fazer proxy de assinatura. Mas usar várias contas pode ter regras próprias em cada provedor: leia os termos de uso de cada um.

Preciso de mais de uma conta?

Não. Com uma conta você já tem a conversa com cada passo à vista, o quadro, os agendamentos e o cérebro. O rodízio entra quando você logar a segunda.

Dá trabalho instalar?

São quatro comandos no Terminal, com o Bun e as ferramentas de linha de comando do Xcode instalados. O último roda os testes e monta o app. Depois, cada conta entra pelo login do CLI dela.

Funciona com o Gemini e o Grok?

Funciona, com limites. Aprovação por ação e texto ao vivo só no Claude. As ferramentas para agentes só no Claude e no Codex. O Grok responde como texto único.

E no Windows ou no Linux?

O app é só para macOS 13 ou mais novo com Apple Silicon. O servidor roda em Linux, onde os testes rodam, mas sem a janela nativa.

Quanto custa?

Nada. É código aberto, licença MIT. Você continua pagando só os planos que já tem com cada provedor.
